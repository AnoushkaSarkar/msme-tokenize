##  The Problem

India has **63 million MSMEs** contributing ~30% to GDP and employing **110 million+ people** — yet **80% lack access to formal capital**. Traditional financial systems exclude small businesses due to high entry barriers, lack of credit history, and absence of intermediary trust.

---

##  Our Solution

**MSME Tokenize** bridges this gap by bringing fractional equity ownership to the masses using blockchain. Any investor can buy equity in a verified small business for as little as ₹100 — with full transparency, no intermediaries, and automated profit sharing.

 **Live at:** [msme-tokenize.vercel.app](https://msme-tokenize.vercel.app/)

---

##  How It Works

```
MSME onboards via GST verification
        ↓
Smart contract issues ERC-20 tokens (fractional equity)
        ↓
Investors connect MetaMask → buy tokens using MATIC
        ↓
Profits trigger automated dividend distribution to wallets
        ↓
Token holders vote on governance decisions (1 token = 1 vote)
```

##  Blockchain Architecture

| Layer | Detail |
|---|---|
| **Network** | Polygon (PoS) |
| **Token Standard** | ERC-20 per MSME |
| **Wallet** | MetaMask |
| **Transaction Speed** | < 2 seconds |
| **Gas Fees** | < ₹1 per transaction |
| **Explorer** | Polygonscan (fully verifiable) |
| **Dividends** | Auto-distributed via smart contract |
| **Governance** | On-chain voting (1 token = 1 vote) |

Each MSME gets its **own ERC-20 smart contract** on Polygon representing immutable fractional ownership. All transactions are cryptographically signed and publicly verifiable — no intermediaries.

##  Getting Started

### Prerequisites

- Node.js v16+
- MetaMask browser extension
- MATIC tokens (for transactions on Polygon)

### Installation

```bash
# Clone the repository
git clone https://github.com/AnoushkaSarkar/msme-tokenize.git

# Navigate into the project
cd msme-tokenize

# Install dependencies
npm install

# Start the development server
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### MetaMask Setup

1. Install the [MetaMask extension](https://metamask.io/)
2. Add the Polygon network (Chain ID: 137)
3. Fund your wallet with MATIC
4. Connect wallet on the platform and start investing
